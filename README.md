

Retail Store Inventory Management System
An interactive, multi-location Excel inventory management system built to monitor stock health, track inventory valuations across product categories, and automate reorder alerts across 5 retail hubs.


 Project Overview
This project processes and analyzes a dataset of 5,000 products across 5 key categories (Clothing, Electronics, Furniture, Groceries, and Toys) across 5 store locations (Ahmedabad Branch, Delhi Warehouse, Mumbai Store, Online, and Pune Store).


Key Objectives:
•	Track Inventory Valuation: Calculate and monitor total stock value (₹46.98 Cr) and total quantity across categories and locations.

•	Automate Reorder Alerts: Identify low-stock and out-of-stock items dynamically to enable proactive replenishment.

•	Interactive Data Exploration: Provide an intuitive dashboard equipped with interactive pivot tables and slicers.

 Key Features & Highlights
•	Data Cleaning & Structure (Cleaned_Data): Standardized product IDs, names, category classifications, supplier names, stock levels, cost metrics, restock dates, and product statuses.

•	Conditional Formatting: Automated visual highlighting for critical stock statuses (In Stock, Low Stock, Out of Stock) and Reorder Alert flags (OK vs REORDER NEEDED).

•	Dynamic Valuation Calculations: Computed total stock values using Excel formulas (Total Value = Quantity in Stock * Cost per Unit).

•	Pivot Table Analytics (Pivot_Summary): Multi-axis aggregations summarizing total inventory value and quantity by category, stock status distribution, and location-wise totals.

•	Interactive Dashboard (Dashboard): Visualized key insights using combo charts, donut charts, and horizontal bar charts linked dynamically with interactive slicers.

 Excel Workbook Structure
1.	Cleaned_Data: Contains the complete cleansed dataset of 5,000 product rows with raw inputs and calculated columns.

2.	Pivot_Summary: Centralized pivot tables categorizing stock status, location totals, and product category aggregations.

3.	Dashboard: Visual control panel featuring interactive charts (Value vs Quantity combo chart, Stock status distribution donut chart, Location breakdown bar chart) and slicers for fast filtering.

 Tech Stack & Tools Used
•	Microsoft Excel: Advanced Formulas ,Pivot Tables, Conditional Formatting, Data Validation.

•	Data Visualization: Combo Charts, Donut Charts, Horizontal Bar Charts, Interactive Slicers.

 How to Use the Excel File
1.	Download or clone this repository.

2.	Open Retail Store Inventory Management.xlsx in Microsoft Excel 2016 or newer.

3.	Navigate to the Dashboard tab.

4.	Use the interactive Category, Store Location, or Stock Status slicers to dynamically filter data across all visualizations.
